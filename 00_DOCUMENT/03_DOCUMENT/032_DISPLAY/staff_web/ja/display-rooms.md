# スタッフWeb: Room Master（部屋マスタ）

## 画面概要
部屋の一覧・検索・フィルタ、追加・編集。ポイント/ Kudos 設定（ops 用）。

## パス
`/staff/rooms`, `/manager/rooms`

## 表示項目

| 項目 | 説明 |
|------|------|
| 検索 | 部屋番号・ラベルで検索 |
| フィルタ | all / available / occupied / inactive |
| 部屋一覧 | フロア別、部屋番号、定員、ステータス、ラベル |
| ポイント設定 | 1 Kudos あたりのポイント（編集可能） |
| 追加ダイアログ | 部屋番号、フロア、定員、ステータス、ラベル |
| 編集ダイアログ | 同上 |

## 操作・アクション

| 操作 | 動作 |
|------|------|
| 追加 | 部屋を新規作成 |
| 編集 | 部屋情報を更新 |
| 検索・フィルタ | 一覧を絞り込み |

## 備考
- 現状はモックデータ。将来 ops-rooms と CRUD API で連携予定。
