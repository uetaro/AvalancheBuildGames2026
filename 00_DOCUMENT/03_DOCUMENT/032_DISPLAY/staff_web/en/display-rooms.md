# Staff Web: Room Master

## Screen Overview
Room list, search, filter, add, edit. Point/Kudos settings (ops).

## Path
`/staff/rooms`, `/manager/rooms`

## Display Items

| Item | Description |
|------|------|
| Search | Search by room number, label |
| Filter | all / available / occupied / inactive |
| Room list | By floor, room number, capacity, status, label |
| Point settings | Points per Kudos (editable) |
| Add dialog | Room number, floor, capacity, status, label |
| Edit dialog | Same as above |

## Actions

| Action | Behavior |
|------|------|
| Add | Create new room |
| Edit | Update room info |
| Search/filter | Narrow list |
