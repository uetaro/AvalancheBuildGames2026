# Staff Web: Login Screen

## Screen Overview
Login for staff/manager web admin. Authenticate with Supabase Auth.

## Path
`/`

## Display Items
- Logo, brand
- Email input
- Password input
- Login button
- Error message

## Actions
- Login: signInWithPassword
- On success: Navigate to /staff or /manager based on role

## Navigation
- /staff — Staff
- /manager — Manager
