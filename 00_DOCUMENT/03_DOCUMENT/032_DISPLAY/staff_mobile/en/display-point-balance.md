# Staff Mobile: Point Balance

## Screen Overview
Display point balance, this month's earned, and 6-month trend.

## Path
`/app/point`

## Display Items

| Item | Description |
|------|------|
| balance | Total point balance |
| this_month | Points earned this month |
| monthly_trend | Point trend for past 6 months |

## Actions

| Action | Behavior |
|------|------|
| History | To /app/point/history |
| Exchange | To /app/point/exchange or /app/point/exchange-list |

## API
- GET my-point-balance

## Navigation
- /app/point/history — History
- /app/point/exchange-list — Exchange list
- /app/point/exchange — Exchange
