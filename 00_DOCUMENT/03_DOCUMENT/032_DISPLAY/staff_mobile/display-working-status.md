# スタッフモバイル: 勤務状態画面

## 画面概要
出退勤状態の表示と、NFC タップで出退勤（work-tap）を実行する。

## パス
`/app`（index）, `/app/work`

## 表示項目

| 項目 | 説明 |
|------|------|
| 現在時刻 | 1秒ごとに更新 |
| 勤務状態 | 出勤中 / 退勤中 |
| 出勤開始時刻 | 出勤中の場合 |
| タップボタン | 出退勤実行（NFC シミュレート） |
| デバッグパネル | タグ一覧、選択、送信テスト |
| トースト | 成功/エラー/情報メッセージ |

## 操作・アクション

| 操作 | 動作 |
|------|------|
| タップ | work-tap API を POST（work_tag_public_id） |
| デバッグパネル | work-tags 取得、タグ選択、送信 |

## API
- GET work-status
- POST work-tap
- GET work-tags（デバッグ）

## 遷移先
- /app/work/activity — 勤務履歴（任意）
