# 032_DISPLAY — 画面仕様書 / Display Specifications

日本語版と英語版の両方を用意しています。

## 言語別フォルダ

| フォルダ | 言語 |
|----------|------|
| **ja/** | 日本語 |
| **en/** | English |

## アプリ別構成

- **guest_mobile/** — ゲスト向けモバイルアプリ
- **staff_mobile/** — スタッフ向けモバイルアプリ
- **staff_web/** — スタッフ/マネージャー向けWeb管理画面

各アプリ配下に `ja/` と `en/` があり、それぞれに画面仕様を格納しています。

## 各画面仕様の内容

- 画面概要 / Screen Overview
- 表示項目 / Display Items
- 操作・アクション / Actions
- 遷移先 / Navigation
- 備考 / Notes
